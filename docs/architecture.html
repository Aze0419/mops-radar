MOPS 飆股雷達系統架構

每日收盤價寫進 Supabase，凌晨掃 MOPS 重大訊息公告配合股價算本益比、AI 分析，早上推播 Telegram 與 Google Sheet。同一支 repo 裡兩支腳本的實際執行位置不一樣，是這個系統最容易踩的坑。

兩支腳本、兩個執行位置

  • fetch_prices.py：2026-09-07 起改跑本機 git clone
  • mops_radar.py（scan/send）：仍在 Google Drive，靠 runner 包一層避開掛載卡住
  • 改 Google Drive 那份程式碼要記得同步回本機 clone

scan / send 交接

  • scan（00:30）只分析存檔，不送出
  • send（07:00）讀 cache 送 Telegram，送完才刪
  • cache 還在 = send 失敗，資料沒丟，可補送

防呆設計

  • runner.py：timeout + 最多 4 次重試（15/30/60s 退避）
  • 股價一律查 Supabase，不讓 AI 自己編
  • Telegram HTML 標籤沒配對就降級純文字，避免整則被拒收
